# Лазерный канал связи на ESP32-S3

Сайт-описание проекта: передатчик (ESP32-S3 + лазер KY-008) и приёмник (ESP32-S3 + фотодиод BPW34 + MCP6002 + экран ST7789).

## Важно
`index.html` — **самодостаточный**: 3D-модели, чертежи, PDF и STL для скачивания встроены прямо в файл.
Для работы сайта достаточно загрузить в репозиторий один `index.html`. Остальное — дополнительно:
- `stl/` — те же 5 STL-файлы отдельно
- `drawings.pdf` — чертежи
- `generator/` — Python-скрипты, из которых собраны корпуса (параметры в `gen3.py`)

## Как выложить на GitHub Pages
1. Создайте репозиторий и загрузите файлы (минимум `index.html`) в корень.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

3D-просмотрщик подгружает библиотеку three.js с CDN (jsDelivr), нужен интернет.

## Печать
Чёрный PETG или PLA, слой 0,2 мм, 4 периметра, заполнение от 30%. Детали лежат так, как их печатать.
Крышки с мостами 15–19 мм: включите поддержки или мосты.
