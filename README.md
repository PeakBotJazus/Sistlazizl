# Лазерный канал связи на ESP32-S3

Передатчик (ESP32-S3 + лазер KY-008) и приёмник (ESP32-S3 + фотодиод BPW34 + MCP6002 + экран ST7789):
корпуса для 3D-печати, интерактивная 3D-модель с разбором, чертежи и описания.

## Что внутри
- `index.html` — сайт (одна страница, без сборки)
- `assets/` — чертежи (PNG) и сжатые модели для 3D-просмотрщика
- `stl/` — 5 файлов для печати
- `drawings.pdf` — чертежи, 4 листа
- `generator/` — Python-скрипты, из которых сгенерированы корпуса (параметры в `gen3.py`)

## Как выложить на GitHub Pages
1. Создайте репозиторий и загрузите все файлы из этой папки в корень.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

Локально можно просто открыть `index.html`. 3D-просмотрщик подгружает three.js с CDN (jsDelivr), нужен интернет.

## Печать
Чёрный PETG или PLA, слой 0,2 мм, 4 периметра, заполнение от 30%. Детали лежат так, как их печатать.
Крышки с мостами 15–19 мм: включите поддержки или мосты.
